<h1 align="center">3xBoard</h1>

<p align="center">
  Управление панелями 3x-ui на VPS/VDS серверах под управлением Linux для Android устройств.
</p>

---

## Возможности

- Мониторинг
- Установка, настройка и управление панелями, подключениями и клиентами.
- Подключение серверов с уже установленными панелями 3x-ui по API Token или SSH.
- Подключение к "чистому" серверу и установка 3x-ui последней актуальной версии из приложения.
- Встроенный мини-терминал.
- Создание каскадов за три шага и настройка маршрутизации.
- Работа с серверами по SSH.
- Отсутствие рекламы и платных подписок!
- Полностью открытый исходный код

**Проект находится в развитии. Периодически добавляются новые функции, улучшения, правки. В приложении реализована функция обновления до актуальной версии**

**Поддержка:** Android 10+
**Поддержка серверов Linux:** Debian/Ubuntu
**Поддержка 3x-ui** версии 3.10+ (поддержка более ранних версий не гарантирована)
